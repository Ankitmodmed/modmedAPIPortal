That is why we developed our EMA Proprietary API and work with practices to connect with many of the vendors featured in the [ModMed synapSYS Marketplace](https://modernizingmedicine.force.com/synapsysmarketplace/s/).

Our proprietary API allows connected applications to take advantage of some of the key functionality of our EMA® EHR and Practice Management software, helping to create a smoother experience for our customers.
