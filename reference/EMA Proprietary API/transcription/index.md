MMI has developed functionality which allows 3rd party vendors to send transcribed or ‘textual’ content either directly into an unfinalized visit note or as a stand-alone chart note. If the customer wants to use the Transcription workflows, a Firm Admin can also navigate to "Manage Firm Preferences":

![Administrator view of Firm Settings](https://files.readme.io/7a2bbf987798d3ec76aa34e409286cbb858ee011637aa7e6a781b2a3ade6317e-image.png)

and set Enable Transcription Status to ‘ON’:

![Enable Transcription Status](https://files.readme.io/4b8621456028120832fdc4bbc68adbcf0f252d5f787c3da3b7124017ffab1f0b-image.png)

**User Experience**\
Depending on the customer and or workflow, either of these experiences can be or may be accommodated. If there is an unfinalized encounter (visit) for a patient, AND the provider has marked the encounter as ‘HELD FOR TRANSCRIPTION’:

![View of a preliminary visit note in the workflows tabs with the "Hold for Transcription" button highlighted](https://files.readme.io/495eb339a32b96800d32e04588f9c583c35bf832b022027c22c454cef96f4e1a-image.png)

THEN, the vendor can send in text that will appear inside the ‘Additional Visit Notes’ section of the Visit note:

![Review transcription modal with buttons to Review Later or to Accept](https://files.readme.io/0a78bb6ab05bd4545512997dd0f060109959326f83d63cbf08c7030ecb90a5c4-image.png)

An end user will know IF transcription has been received:

![Patient activity card with a status column that shows "Transcription Received Visit" highlighted](https://files.readme.io/cd4f6c025003ba69ec6241b31f53ca69234295fc327f87467b9e80c8117a9c95-image.png)

Once the transcription has been received,, the provider can either accept it or edit it to their liking before accepting the text into the Visit Note.\
You will notice that a Transcriptionist also has a space to add notes to the Provider. This is helpful for situations where perhaps the provider was dictating, but the transcriptionist wasn’t sure about something the provider had said. They could communicate something like that in this space.
Once it has been accepted, it will appear here in the visit note:

![View of visit note pdf with the Notes field highlighted](https://files.readme.io/0faa0a54832212c5e832927ff51fed67f69716340beb7fee2d5d70347edceabe-image.png)

If there is no visit or the visit is not marked as ‘HELD FOR TRANSCRIPTION’, then when the vendor sends text, it will create a new Chart Note:

![View of note history with a new chart note with the status "Transcription Received"](https://files.readme.io/97161f34d2db6da6e68f66e121ae52117efb78d86c21a39bd111d3e4a82852ab-image.png)

![View of visit note with the action buttons to Edit Note, Reject, View Note PDF, Accept and Finalize, and Create Task](https://files.readme.io/97161f34d2db6da6e68f66e121ae52117efb78d86c21a39bd111d3e4a82852ab-image.png)

From this screen, the provider can either accept it or edit it to their liking before finalizing the Chart Note.
