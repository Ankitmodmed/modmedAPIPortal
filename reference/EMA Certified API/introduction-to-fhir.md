ModMed implements the R4 Version of the HL7® FHIR® standard. It is recommended that you become familiar with the standard by checking out the wealth of information provided by the HL7 organization. Here is a good starting point.

The MMI Certied FHIR API supports both the EMA/MMPM Platform as well as the gGastro Platform. The MMI Certied FHIR API is intended to be used for the purpose of the exchange of health information included in the [U.S. Core Data for Interoperability](https://www.healthit.gov/isp/united-states-core-data-interoperability-uscdi).
